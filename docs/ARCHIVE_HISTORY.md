# Archive history

The canonical COVER-Fish data releases are the three Zenodo records listed in
[Citation](../CITATION.md). This page records earlier immutable Hugging Face
snapshots for provenance and fallback access. They are not competing current citation
targets.

## Historical full-payload snapshot

- DOI: [`10.57967/hf/9776`](https://doi.org/10.57967/hf/9776)
- fixed revision: `4e437b6a2bf5f9a12a200bbe3a93411fe713db1f`
- role: immutable historical payload snapshot and fallback access point

The Zenodo release reorganizes the same scientific objects into independently
citable evaluation, reference-update, and Commons records. Some containers were
repackaged, so the Zenodo records must not be described as binary-identical
mirrors of this historical snapshot.
